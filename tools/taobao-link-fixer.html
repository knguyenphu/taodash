🔗 Taobao Link Fixer

Paste one or more Taobao / Tmall / world.taobao.com links (one per line). Each gets converted to the canonical item.taobao.com/item.htm?id= link your purchasing agent needs.

Links that already contain a plain numeric id (most item.taobao.com / detail.tmall.com links) resolve instantly. Opaque world.taobao.com links are resolved by fetching the live page through a public CORS proxy and reading the id out of it — this only works once the page is served online (e.g. GitHub Pages), not opened as a local file.
